# declaration_parser

Локальный Python-скрипт для парсинга PDF-файлов таможенных деклараций (ДТ) и выгрузки в единый Excel-отчёт.

## Что делает

- Берёт все PDF из `./input/`.
- Для каждого файла извлекает обязательные поля:
  - номер декларации (графа A),
  - дата (графа 54),
  - транспорт (графа 18),
  - отправитель (графа 2),
  - получатель (графа 8),
  - инвойс (код `04021/0`, графа 44),
  - контракт (код `03011/2`, графа 44),
  - описание товаров (графа 31, объединяется),
  - общий вес брутто (сумма по графе 35),
  - общий вес нетто (сумма по графе 38),
  - общая таможенная стоимость (графа 12).
- Приводит числовые поля к `float` (запятая автоматически конвертируется в точку).
- Формирует один файл `logistics_report.xlsx`, где 1 PDF = 1 строка.

## Установка зависимостей

```bash
pip install pdfplumber pandas openpyxl
```

## Запуск

```bash
python parse_declarations.py --input ./input --output logistics_report.xlsx
```

Во время выполнения выводится прогресс:

```text
Processing [1/N]: file.pdf...
```

Если один PDF повреждён или не парсится, скрипт выведет предупреждение и продолжит обработку остальных файлов.
